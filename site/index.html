Cada ponto é um ano de 1959 até hoje. As cores vão do azul (anos mais antigos) ao vermelho (mais recentes).

Sobre a precisão dos dados. Os dados dos anos 0–1849 (temperatura) e 0–1958 (CO₂) são valores aproximados, por década ou meio século, que reproduzem a forma geral das reconstruções publicadas (PAGES 2k, Law Dome). Servem para ver a tendência, não para citar valores exatos. As séries modernas vêm de bases oficiais.
  • Temperatura 1850–hoje: NOAA (GCAG), reajustada para a base 1850–1900. O ano mais recente pode estar incompleto.
  • CO₂ 1959–hoje: NOAA, Mauna Loa.
  • Emissões: CDIAC / Global Carbon Project (conversão de C para CO₂ × 3,664).
